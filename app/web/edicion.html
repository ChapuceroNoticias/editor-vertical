Atajos de teclado
Haz clic en un bloque de la línea de tiempo para seleccionarlo (queda con borde blanco).
Ctrl+C copiar el bloque · Ctrl+X cortar · Ctrl+V pegar donde está el cursor · Ctrl+D duplicar justo después
Supr / Retroceso borrar el bloque (en «Pantalla» lo deja en Solo Nacho)
Ctrl+B o S partir en dos donde está el cursor
[ el bloque empieza en el cursor · ] el bloque termina en el cursor
Alt+← / → mover el bloque un cuadro · Alt+Shift+← / → un segundo
Ctrl+Z deshacer · Ctrl+Y o Ctrl+Shift+Z rehacer
Espacio reproducir/pausa · ← / → un cuadro · Shift+← / → un segundo · Inicio / Fin principio o final
Tab seleccionar el siguiente bloque · Esc quitar la selección
Alt mientras arrastras: sin imán · Ctrl+S: todo se guarda solo
